# Avatars

Drop one image per agent here, named after the agent id.

```
Warrior.png
Shaman.png
Hunter.png
Paladin.png
Peon.png
Warlock.png
```

Supported: `png`, `jpg`, `jpeg`, `webp`, `gif`.

No artwork is bundled with this repository. Add your own images, or point the
`directory` option at a folder outside the repo.

This folder is ignored by git except for this file, so personal portraits are
not committed by accident.
